# Evidence-validity framing（论文概念框架 v1）

> 把本工作的科学叙事从"RL 上下文适应"升级为"真机无碰撞证据验证与在线适应"的机制研究。
> 概念来源：用户提供的 command-measurement-action / evidence-validity 思想
> （UAV 开放任务中，命令不指定动作，而描述需要先验证的任务情境）。
> 本工作是这个哲学在**单命题**（"窄缝可穿越"）上的最小化实例。

## 核心重述

本文最终要证明的是**真机运行时**的能力。仿真中的策略训练和碰撞标签只能用于准备与筛选，
不能替代真机证据。真机试探必须在独立安全层允许的动作集合内进行，碰撞、擦碰或保护罩接触
不得作为学习反馈。

- **命令**：穿越这个未知窄缝。命令不给出下一动作，也不给出缝的真值；
  任务相关事实——缝的真实尺寸/朝向/是否可行——必须由飞行本身验证。
- **measurement query**：每次进近是一次测量查询——
  *"在当前视角/进近轨迹 V 下，命题 P=『窄缝可穿越且保留刹停余量』能否被接受
  （置信度 τ）？"* 可接受 → 继续承诺；不可接受 → 中止（拒绝命题）。
- **证据转移**：每次尝试产生四类证据转移（对应记忆内容）：
  - 语义：缝中心偏移（该往哪调）；
  - 可见性：边缘/净空在什么范围可观测；
  - 概率：可穿越置信度的变化；
  - 可行性：控制余量/刹停距离的收缩。
- **危险失败 = 假确定性**：把"看起来可穿"当作"已验证可穿"（把影子当裂缝）。
  当前系统的失败模式正是它——策略全速冲进、80% 穿过、20% 撞墙，从不验证后拒绝。

## 本系统如何实例化它

| 概念 | 本系统 |
|---|---|
| 任务状态（假说/缺失证据/置信度/停止条件） | 可审计的任务记忆（可包含 GRU 隐状态、几何/动力学估计和不确定性） |
| 测量查询（接受/拒绝命题） | 进近→commit 或 abort 的二值决策 |
| 证据转移预测 | 辅助头（净空回归 / 0.5s 内碰撞概率 / 本次尝试成败） |
| 保留恢复选项（短视距+可停/可退/可重观测） | progressive commitment（README §3）；中止时仍有余量（abort 净空指标） |
| 避免假确定性 | give-up on infeasible（正确拒绝"不可穿越"命题） |
| 基于已检验证据行动 | 同一真机任务中，历史改变后续动作且在历史替换对照下保持收益 |

## 论文定位句（Discussion 可用）

> 我们把"未知任务上的安全试探"重述为**真机证据有效性**问题：无人机必须先验证
> '可穿越'命题，再承诺动量；未经检验的线索（看似可穿）必须被显式拒绝而非接受。
> 本工作在单命题窄缝任务上证明：这样一个验证-承诺循环可以**端到端学习**出来，
> 且其机制（跨尝试证据记忆、风险估计驱动的拒绝）可以被受控实验因果验证。

## 与"能力为本"的一致性

本框架不绑定 RL：任何能维护任务状态、产生测量查询、并按证据接受/拒绝命题的
系统（规划+学习、世界模型、模仿）都能在此评估协议下评测。RL 是本工作选择的
一条获取路径；评估协议（attempt 条件成功率、wipe、abort 余量、假确定性避免率）
是方法无关的。

## 新增可量化指标（可选，增强评估）

- **假确定性避免率**：在不可穿越实例上，策略应"放弃"而非"撞墙"（正确拒绝 vs 接受假命题）。
- **过度自信率**：在"可穿但极窄"实例上，直接撞墙（没有先探测/中止）的比例。
- **证据收益**：中止后下一次尝试的对准误差或安全裕度改善（证明真机证据被使用）。
- **无碰撞适应率**：在零接触任务中，第二次方案相对第一次方案的可重复改善比例。
- **安全信息效率**：单位安全试探时间带来的不确定性下降或成功概率提升。
- **风险估计校准**：辅助头碰撞预测的 AUROC + 可靠性图（策略的拒绝依据是否可靠）。

## 实现该框架的两条候选路径（方法可替换）

本框架只规定"证据验证先于承诺"的行为，不绑定具体实现。两条已记录的获取路径：

1. **冻结基础策略 + 真机任务记忆（首选验证路径）**：在安全约束内从真实观测形成"测量→接受/拒绝→承诺"；
   风险估计（辅助头）驱动中止，跨尝试记忆积累证据。
2. **大语言模型/视觉-语言模型思维链（LLM chain-of-thought，记录为候选方案）**：
   分层结构——LLM 作为**高层决策器**（低频 ~1Hz，思维链显式推理命题 P="可穿越且保留
   刹停余量"是否被验证，据此发出 继续/中止掉头/调整策略/放弃 命令），**低层执行器**
   （传统控制器或学习到的低层策略，40Hz）执行动作。LLM 的思维链正是"避免假确定性"的
   显式机制：它列出证据、缺失证据、候选视点、置信度，再决定接受还是拒绝 P。
   详见 docs/tech-selection.md §11。

两条路径共享：自我中心观测接口、CTBR 动作接口、独立安全层和方法无关的评估协议（无碰撞试探、
安全裕度、证据收益、历史替换对照）。仿真结果和真机结果必须分开报告。
