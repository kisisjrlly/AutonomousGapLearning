# 真机无碰撞在线适应规范

## 仿真先行验证原则

**仿真与真机共享同一验收标准**，区别仅在于物理真实性，而非任务定义或安全约束。

仿真阶段必须先按本规范验证完整闭环：面对训练分布外的未知窄缝，策略在零碰撞、零擦碰、零接触约束下完成安全试探、主动中止、退出、证据收益和历史替换对照。仿真通过后才进入真机阶段，真机阶段在真实传感器噪声、动力学不确定性和不可逆后果下复现该能力。

仿真不是"降低标准的训练场"，而是"可控环境中的真机标准预演"。

## 目标

无人机在未知窄缝前进行低风险试探；在仍有可恢复轨迹时主动中止并退出；将试探得到的几何、动力学或观测可信度摘要用于下一次动作。碰撞、擦碰和保护罩接触均视为安全失败，不能作为学习反馈。

## 安全闸门

每个控制周期由独立安全执行层检查状态估计不确定性、扫掠体积、制动距离、控制延迟和退回轨迹。检查失败时只允许悬停、减速、掉头或放弃；策略输出不能绕过闸门。必须配置硬件急停、软质测试环境、人工接管和可审计日志。

## 在线适应定义

第一轮试探必须产生可记录的任务相关证据；第二轮动作须出现与该证据对应、可重复的改变。以同一物理场景替换或清空历史作为对照；若收益不下降，不能声称使用了经历。首阶段冻结基础策略参数，只更新受限任务记忆或低维安全参数。

## 必报指标

零碰撞、零擦碰、零保护罩接触；安全层介入率与急停次数；每次试探的最小安全裕度、退出成功率和信息收益；历史替换对照差异；真实传感器延迟、估计不确定性和最终任务成功率。
