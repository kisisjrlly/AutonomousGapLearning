# 技术选型文档（阶段0交付物）

> 对应 README §16 要求的首项任务：在编写训练代码前，确定平台、仿真器、传感器、动作空间、
> 时序模型、训练算法、安全边界、数据格式与阶段1验收指标。
> 日期：2026-07-26。硬件现实：单卡 RTX 4080 16GB，32 核 CPU，62GB 内存。

每项决策标注其服务的研究假设（H）与评估指标（M，编号对应 README §12）。

## 0. 研究假设编号

- **H1**（统一策略）：单一长时序端到端网络可以让"观察—试探—中止—退出—调整—重试"作为行为涌现，无需人工任务状态机。
- **H2**（上下文适应）：权重冻结时，跨尝试保留的记忆可显著提升第2/3次尝试的条件成功率（方案A）。
- **H3**（安全中止学习）：以主动中止而非碰撞作为主要"失败"数据源，策略可以在低接触率下学到窄缝可行性判断。
- **H4**（任务分布泛化）：在参数化窄缝分布上元训练的策略能泛化到保留参数区间，且性能提升确实来自历史利用而非固定动作记忆。

## 1. 仿真器：自研 GPU 向量化仿真（PyTorch）

**决策**：不使用 Isaac Sim / MuJoCo / Genesis，自研全批量 PyTorch 仿真器，物理 200 Hz 子步，控制 40 Hz，`N=2048–8192` 并行环境全部驻留 GPU。

**理由**（对照 README §11 的选型标准）：
- *并行效率*：方案A的元训练需要"多次尝试的长 episode"（本项目 960 步/24 s），样本需求量级 1e8–1e9 步。单卡 4080 上只有全 GPU 向量化（仿真、渲染、策略前向同卡零拷贝）能达到该吞吐；Isaac Sim 的渲染吞吐和显存开销在 16GB 单卡上无法同时支撑数千环境 + 视觉。
- *动力学接口*：窄缝任务的关键物理量（刚体姿态、电机迟滞、控制延迟、风扰）都是低维 ODE，自研实现可控且便于域随机化（README §10 的全部扰动维度都是仿真器一等公民）。
- *传感器延迟建模*：自研管线中观测延迟、动作延迟为显式环形缓冲，可逐环境随机化。
- *代价*：牺牲照片级渲染。视觉真实性缺口由域随机化 + 论文中明确的 sim-to-real 边界声明处理（本阶段为纯仿真研究）。
- 场景为解析几何（带矩形孔的有限厚墙 + 地面 + 天空），光线求交为闭式解，无需网格/BVH。

**碰撞与净空**：机体近似为带桨保护罩的扁圆柱（半径 0.16 m、半高 0.05 m），
以有向圆柱对墙体（带孔长方体）做解析最近距离，得到逐步净空 `c_t`；`c_t<0` 判接触，
按接触时刻动能区分软接触与高能碰撞（README §9 的三级事件）。

## 2. 传感器：低分辨率平面着色 RGB + IMU + 本体状态

**决策**：第一版视觉为 32×24×3 平面着色 RGB（光线投射：墙面/背景/地面随机反照率 + 距离衰减 + 光照增益随机化 + 像素噪声），不提供深度真值、不提供窄缝相对位姿真值。

**理由**：README §8.1 首选 RGB；平面着色光线投射与深度图成本相同，但保留"从外观推断几何"的核心难度与域随机化维度（纹理、光照）。事件相机/双目/深度作为后续对照（README §15 问题1），不进入 v1。

其余观测：机体角速度与线加速度（噪声+偏置）、重力方向估计（噪声）、速度估计（模拟 VIO：噪声+随机漂移）、相对起飞点高度（噪声）、上一动作、电机一阶状态。**不包含**任何窄缝几何真值或"当前第几次尝试"的显式标志（对应 H1/H4：分段行为必须自己涌现）。

## 3. 动作空间：总推力 + 机体角速度（CTBR），40 Hz

**决策**：`a_t = [T, ωx, ωy, ωz]`，内环为仿真的角速度 P 控制器 → 力矩 → 电机一阶迟滞（时间常数随机化 20–60 ms）→ 刚体。动作经逐环境随机延迟（0–50 ms）执行。

**理由**：README §4/§8.2 明确此为现实边界；成熟飞控（Betaflight/PX4 rate 模式）可直接承接该接口，保留 sim-to-real 通路。动作块（action chunk）作为消融变体而非 v1 默认（README §15 问题3）。

## 4. 时序模型：CNN 编码器 + GRU 长上下文

**决策**：小型 CNN（3 层卷积）编码图像 → 与状态向量拼接 → 单层 GRU（隐藏 512）跨整个 episode（含全部尝试）持续携带隐状态 → 高斯动作头 + 价值头 + 辅助预测头。

**理由**：
- 960 步 × 数千环境的 Transformer 全上下文注意力在 16GB 上与 PPO 不兼容；GRU 以 O(1) 状态实现无限上下文，且部署侧算力占用最小（README §12 最后一条指标）。SSM/Transformer 列为后续对照（README §15 问题2）。
- 辅助头（预测未来净空、本次尝试成功概率、短期碰撞概率）仅参与训练损失，部署时不读取——README §8.3 明确允许，且辅助头输出不进入任何控制分支，杜绝演变为人工状态机。
- 价值头使用非对称评论家（可见特权状态：真实相对位姿、真实净空），演员严格不可见。此为标准做法，只影响训练效率，不改变部署端到端性质。

## 5. 训练算法：循环 PPO + 约束优先多目标奖励 + 课程

**决策**：Recurrent PPO（截断 BPTT，块长 64，隐状态跨块传递；rollout 期间隐状态跨尝试、跨 rollout 边界持续），奖励按 README §11 的五级优先序设计；窄缝宽度/扰动强度用自动课程（按成功率调度）。方案A（上下文适应）为本阶段唯一在线适应机制：**部署与评估时权重冻结**。

拒绝方案（README §16 红线自查）：不用真实碰撞作为主要数据机制（碰撞在训练早期不可避免，但奖励结构使其随训练衰减并在指标中全程记录，见 M7）；不写任务状态机（环境侧的 attempt 分段仅用于奖励事件与指标测量，不输入策略）；主动中止不标注为"必然碰撞"标签（辅助头的碰撞标签只来自真实碰撞的事后回溯）。

## 6. 任务分布与数据划分

窄缝参数（宽 0.34–0.90 m、高 0.30–0.80 m、厚 0.05–0.30 m、面内滚转 ±40°、墙距 2.5–4.5 m、中心高度 1.0–2.2 m）+ 动力学参数（质量 ±25%、惯量 ±30%、延迟、风 0–2.5 m/s 阵风）+ 视觉参数联合随机。机体直径 0.32 m（含罩），故宽度低端必须侧身通过；分布含约 8% 几何不可行实例（缝小于机体最小扫掠截面），用于"有限次尝试后放弃"行为（README §15 问题10）。

**划分**：以参数区间划分训练/验证/测试；另设外推测试集（宽度、风、质量各向训练区间外延 15%）。测试任务实例的随机种子固定并版本化。

## 7. 安全边界（仿真阶段）

本阶段为纯仿真，README §9 的最小安全内核以"评估侧影子内核"形式实现：解析刹停可行性检查（当前速度/姿态/推力上限下是否存在不接触的刹停轨迹），仅记录违反率（M8 相关），**不否决动作**。这样论文可以同时报告"策略自身的安全边距"与"若叠加安全内核会改变什么"，而不让安全层替代策略学习（README §15 问题7）。真机部署的独立否决内核列为后续工作。

## 8. 数据与日志格式

- 训练：TensorBoard 标量 + 周期性 checkpoint（模型、优化器、课程状态、RNG）。
- 评估：每 episode 一条 JSON 记录（任务参数、逐尝试分段、事件、指标原始量），聚合脚本产出 §12 全指标表。轨迹级 NPZ 回放用于图表与案例分析。
- 所有实验配置以 YAML 快照存档，运行目录含 git commit hash。

## 9. 阶段1–3 验收指标（本轮研究范围）

- 阶段1（单次穿越）：训练分布内单次尝试成功率 ≥ 70%，高能碰撞率 ≤ 3%。
- 阶段2（主动中止）：窄缝不可行实例上接触率 ≤ 5%，且中止后返回重试区成功率 ≥ 90%。
- 阶段3（上下文适应，核心）：保留测试集上，第2次尝试条件成功率显著高于第1次（配对检验 p<0.01）；尝试间清空记忆的对照使该增益消失或显著降低；限定 5 次尝试内最终成功率 ≥ 85%（可行实例）。
