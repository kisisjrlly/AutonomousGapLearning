# 技术选型：本轮审计后的边界

以 `CONTEXTUAL_WORLD_MODEL_PLAN.md` 为准。旧版逐项选型已归档到 `archive/e5753c7/tech-selection.md`，不能把其中旧 PPO 的吞吐或宽松安全标准用于新系统。

保留 GapEnv 作低成本机制实验，但承认其简化的机体角速度响应、阻力、图像和有限采样碰撞近似。不是完整空气动力学/执行器/实机世界。

先做小型结果代理模型与简单基线；有需要时再增加短时动作条件预测。模型容量、批大小、混合精度支持和机载时延以实际测量确定，不承诺16GB必然能训练某个最终方案。

新数据执行器固定名义推力标定，但使用真值位姿和已知夹具几何，只能作为仿真基础；最终机载输入应明确可获得性、估计误差、坐标系和时间对齐。

真实相机型号/分辨率/机载控制链以本项目实物和标定为准，不把其他无人机项目的相机选型自动当作本项目既定配置。

科学对照优先于增加模型：GP/贝叶斯试验搜索、扰动估计/在线辨识加同一规划器、无上下文模型必须保留。显式元训练与上下文学习不矛盾，但不能冒称未经设计的涌现。
