# 最小安全试探闭环：协议与实现边界

日期：2026-09-18。优先于 `.project/path_comparison.md` 中按动作差异阈值选择架构的旧计划。

## 要回答的问题

在起点无法确认后部通道位置时，安全换视点获得的信息，是否改善同一起始状态下的下一次决策？
碰撞、擦碰或保护罩接触均为安全失败。允许证据不足时放弃，不要求每个任务固定重试次数。
仿真训练允许探索碰撞，与冻结策略的部署式测试严格分开。

## 本次交付：抽象几何参考，不是飞行成果

`agl/eval/safe_probe_reference.py` 是独立二维、静态、全向运动的协议自检，不修改现有 PPO 环境。
前孔一致，后孔中心为 ±0.22 m，宽度为 0.52 m 或 0.25 m；机体以半径 0.16 m 圆盘表示。
初始位置 (0,0)，脚本先走到 (1.4,0)，再到 (1.4,0.4)，获得信息后沿原路退出。

**传感器是人为定义的视点门控测量**，中心误差有界，宽度精确；尚无 RGB 渲染、遮挡或几何估计。
这里的动作和信息提取是手写参考，绝不能据此声称神经网络学会试探，或真实视觉能辨识后孔。
任务只有四类结构，不构成泛化或统计显著性的证据。

安全层使用障碍物真值，只批准整段轴对齐路径；每段起止假设静止，拒绝时停留在原静止状态。
检查的是整段扫掠圆盘，膨胀量包含机体半径、裕度、位置误差、速度×延迟和 v²/(2a)。
此保守几何检查不是 CBF、不是刚体制动仿真，也不是对真机的安全保证。
真值不得流入候选规划器；仅传感器和独立执行层读取真值。必须报告执行层介入，不能把其修正归功于策略。

## 配对对照与日志

完成同一次试探并返回 (0,0) 后分支，各分支共享物理任务、安全参数和静止起点：

- real：保留中心、宽度及误差界；满足裕度才承诺穿越。
- removed：移除任务证据，保守放弃。
- swapped：替换为另一中心的证据，保留宽度和误差界，用于检查错误承诺是否被安全层截断。

记录任务真值（评估侧）、证据、决策、执行轨迹、返回轨迹、最小几何净空、接触、介入、放弃、成功。
无有效试探样本报告不足，不能当成“适应率 0”。参考中的信息收益来自人为构造，不能作为方法优于基线的论文结果。

## 下一关：不能跳过的飞行验证

1. 在渲染、碰撞和任务生成中一致实现厚通道内部结构；用相同初始图像和不同试探视图检查可辨识性。
2. 在现有刚体动力学中验证低速接近、刹停和原路退出；覆盖延迟、执行器限制、扰动与估计误差。
   当前独立门的定义见 `docs/RIGID_BODY_RECOVERY_GATE.md`；先做影子回放和误报/漏报统计，不直接改变策略。
3. 用真实传感器可获得的估计替代真值，明确失效检测和暂停条件；未通过不得进入真机。
4. 在匹配的物理状态、扰动和短期状态估计下替换任务记忆，比较闭环成功、错误承诺、合理放弃和介入率。
5. 再比较 GRU、显式记忆和规划基线。动作 L2 差异仅为诊断，不以 0.05/0.1 阈值决定架构。

任何接触都使部署式安全验收失败；必须同时报告全部任务分母、可行任务成功率与放弃率，避免“永远不动”的假安全。
有限样本零接触必须附样本量和适用条件，不能写成普遍零风险。
