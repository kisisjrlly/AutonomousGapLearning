## 🎯 实验设计

### 实验1: GRU上下文验证
**核心问题**: GRU是否真的在用历史信息？

**实验方法**:
```python
# 在第2次尝试时，比较两种情况：
action_with_history    = policy(obs_2, hidden_from_trial_1)
action_without_history = policy(obs_2, hidden_reset_to_zero)

# 如果两者差异大，说明GRU确实在利用历史
mean_diff = mean(|action_with - action_without|)
```

**判断标准**:
- ✅ mean_diff > 0.1: **强影响** → 架构已OK，专注训练改进
- 🟡 mean_diff 0.05-0.1: **中等影响** → 需要增强
- ❌ mean_diff < 0.05: **弱影响** → 需要重构架构

---

### 实验2: 尝试次数分析
**核心问题**: 策略是否在多次尝试中改进？

**实验方法**:
```python
# 对每个episode，记录所有尝试
for episode in episodes:
    attempts = []
    while not done:
        result = env.step(policy(obs, history))
        attempts.append(result)
    
    # 统计改进率
    if len(attempts) >= 2:
        if attempts[1].reward > attempts[0].reward:
            improvement_count += 1
```

**判断标准**:
- ✅ improvement_rate > 70%: **学会适应** → 继续优化
- 🟡 improvement_rate 30-70%: **部分有效** → 需要更强的训练目标
- ❌ improvement_rate < 30%: **未学会** → 需要新的损失函数
